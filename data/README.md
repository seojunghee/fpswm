# data/

- `watermark_qr_64.png` — the 64x64 binary QR watermark used in the experiments (copy of `watermark_QR2_64.png`).
- `val_list.txt` — the 200 validation images used for evaluation (relative to the validation folder), written by
  `python tools/make_val_list.py --val-dir <COCO val folder> --n 200`.

COCO images are not included.
